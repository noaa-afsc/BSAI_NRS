# Bering Sea and Aleutian Islands (BSAI) Northern rock sole stock assessment

This repository houses files corresponding to the BSAI Northern rock
sole stock assessment, including any model runs included in final SAFE
documents.

## Source code for the assessment

The source code for this assessment is written in ADMB as is located
here: <https://github.com/noaa-afsc/flatfish_assessment_code>

## Final Stock Assessment Reports

Final stock assessment reports are found here:
<https://www.fisheries.noaa.gov/alaska/population-assessments/north-pacific-groundfish-stock-assessments-and-fishery-evaluation#groundfish-stock-assessments>

## Model runs

### 2026 harvest projections

In 2026, we did harvest projections only for BSAI northern rock sole,
where typically in the past there has been a full assessment in
even-numbered years.

The 2026 harvest projections for producing the executive summary table
are in the folder 2026/harvest_projections. An additional 5-year
projection was done for scenario 3 and is in the folder
2026/five_year_projections. Instructions for running these harvest
projections are in 2026/bsai_nrs_harvest_projection_instructions.qmd and
include code for querying data and making the tables and plots for the
2026 SAFE document.

### 2024 model runs

The final model (24.2) and the previously accepted model with new data
(18.3_new) can be found in the 2024 folder.

### 2022 model runs

The accepted stock assessment model is in the folder
2022/model_runs/c1mod4_2022

The ABC was based on the OFL from the model run
2022/model_runs/c1mod4_francis_2022

A third model run that was included in the 2022 SAFE is
2022/model_runs/c1mod4_francis_estMQbigpriors
